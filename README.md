# IGreen Energy Rio Pardo

Site estático (HTML, CSS e JavaScript puros, sem build) para captação de contatos via WhatsApp.

## Estrutura

- `index.html` — página principal
- `css/style.css` — estilos
- `js/main.js` — menu mobile, links de WhatsApp e ano do rodapé
- `img/` — logotipo e imagens usadas no site

## Publicar no GitHub Pages

1. Suba este repositório para o GitHub.
2. Em **Settings → Pages**, selecione a branch principal e a pasta raiz (`/`).
3. O site fica disponível em `https://<seu-usuario>.github.io/<seu-repositorio>/`.

## Pendências antes de publicar

Procure por `[PREENCHER]` no `index.html` e complete:

- Descrição do serviço de Telefonia Celular
- Respostas das Perguntas frequentes
- Depoimentos de clientes
- Valor do cashback do programa de indicação
- Endereço, Instagram e LinkedIn no rodapé
